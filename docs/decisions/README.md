# Hồ sơ quyết định kiến trúc

ADR ghi lại quyết định làm thay đổi kiến trúc, ràng buộc sản phẩm, invariant dữ liệu, trạng thái bảo mật hoặc dependency lớn.

Các trạng thái:

- `Đề xuất`
- `Chấp nhận`
- `Bị thay thế`
- `Từ chối`

Ngày 2026-09-28, chủ dự án đã phê duyệt ADR-001 đến ADR-004.
